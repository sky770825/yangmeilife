# 廠商圖卡 UI 檢查 2026-07-03

> 2026-07-03T09:14:55+0800 已完成第一批骨架修復。修復報告：`reports/vendor-card-ui-fix-2026-07-03.md`

## 範圍

- 檢查頁面：`nail-service.html`、`beauty-skin.html`、`hair-salon.html`、`kungfu-tea.html`
- 前台廠商數：11
- 檢查重點：縮圖顯示、資料內容、文字大小比例
- 檢查工具：程式碼檢視、Playwright 手機版 390x844、桌面版 1440x1000

## 結論

目前廠商卡片需要調整，優先順序如下：

1. 縮圖與卡片版型需要修正。
2. 按鈕觸控高度需要修正。
3. 相關資料內容已足夠，但官方來源顯示過長，需要改成更容易掃讀的呈現。
4. 文字大小大致可用，但標籤與輔助文字偏小，長店名需要更穩定的兩行策略。

## 主要問題

### 1. 縮圖顯示

目前卡片使用：

- `img` class：`h-52 w-full object-cover`
- 卡片 grid：`lg:grid-cols-2` / `xl:grid-cols-3`

但 `assets/css/tailwind.min.css` 缺少以下 utility：

- `h-52`
- `min-h-10`
- `min-h-[320px]`
- `lg:grid-cols-2`
- `xl:grid-cols-3`

造成結果：

- 圖片高度沒有固定，依原圖比例自然撐開。
- 桌面版沒有形成多欄卡片，卡片變成單欄超寬。
- 桌面版美甲卡片寬度約 `1120px`，縮圖約 `1118x769px`。
- 功夫茶方圖在桌面版變成約 `1118x1118px`，視覺過大。

建議：

- 先修 CSS utility 或改用現有 utility / 自訂 class。
- 廠商卡片圖片建議固定為 `aspect-ratio: 16 / 10` 或 `4 / 3`。
- 手機版圖片高度控制在約 `176-208px`。
- 桌面版卡片應恢復 2 欄或 3 欄，不應單欄超寬。
- 若未來能取得店家實照，應逐步替換 Unsplash 類型圖；目前 10/11 張為情境圖，只有功夫茶是店家/品牌圖。

### 2. 相關資料內容

目前正式卡片內容包含：

- 店名
- 已核實狀態
- 地區
- 電話
- 地址
- 官方來源
- Tags
- 洽詢 / 收藏

資料完整性目前是好的：

- 11 筆前台廠商皆有電話、地址、官方來源。
- 未核實前台廠商為 0。
- 空價格已不再顯示 `null`。

需要調整的呈現：

- 官方來源文字太長，例如 `Relax蕾娜絲官方網站 / Facebook 公開資訊`，在卡片中資訊重量偏高。
- 電話、地址、官方來源都放在同一個灰底區塊，可讀但偏像資料表，不像服務卡。
- `洽詢` 目前有些連 LINE，有些連 Facebook / 官網，行為合理，但最好加上更明確的 label 或 icon 區分。

建議：

- 官方來源改成短文字：`官方頁` / `Facebook` / `官網`，完整來源保留在 report 或 detail view。
- 地區與核實狀態應保留在卡片上方，電話與地址作為主要資訊。
- 可以新增 `營業時間` 一行，但只在有資料時顯示。
- 未來若要做完整版，可把卡片分成「快速卡」與「詳細抽屜 / 詳細頁」。

### 3. 文字大小比例

目前量測：

- 店名：`18px / 28px`，可讀性足夠。
- 聯絡資料：`14px`，可用。
- label 與 tag：`12px`，略小但尚可。
- 狀態 badge：`12px`，可用。

問題：

- 長店名目前可靠換行，但沒有明確兩行上限。
- 行動版按鈕實際高度只有約 `24px`，低於觸控建議的 44px。原因是 `min-h-10` CSS 缺失。
- 桌面版文字比例被超大圖片稀釋，卡片看起來像圖片頁而不是店家資訊卡。

建議：

- 店名保留 `18px`，手機長店名限制 2 行。
- 聯絡資料可維持 `14px`，但電話與地址建議加強字重或圖示。
- Tags 可降權，最多顯示 2-3 個。
- CTA 按鈕改為至少 `44px` 高，符合手機觸控。

## 建議下一步

第一批先做「卡片骨架修復」：

1. 補齊或改寫卡片專用 CSS，讓縮圖、grid、按鈕高度穩定。
2. 手機版固定一欄，圖片使用固定比例。
3. 桌面版恢復 2 欄或 3 欄。
4. CTA 觸控高度提升到 44px。

第二批再做「資訊層級優化」：

1. 官方來源改短 label。
2. 電話、地址、洽詢加入更明確的視覺階層。
3. 長店名兩行限制。
4. Tags 限制數量，降低噪音。

第三批再做「縮圖素材品質」：

1. 優先替換已核實店家的店面或品牌圖片。
2. 沒有實照時使用同分類一致風格的 fallback 圖。
3. 避免不同分類共用過於相似的情境圖。
